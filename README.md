1. Zastosowanie Kohezji:
    Wyraźny podział pól, podział na klasy oraz interfejsy wrzucone w foldery
    Models, Interfaces oraz Services. Kod nie jest wrzucony w jedną klasę,
    która robiłaby wszystko na raz.
2. Coupling:
    Obecność abstrakcyjnych klas oraz interfejsów co sprawia, że elementy systemu
    nie będą od siebie sztywno uzależnione.
3. Uzasadnienie podziału:
    Podział kodu na klasy zawarte w przypisanych im folderach, ułatwia dostęp do nich oraz
    ewentualną możliwość modyfikacji kodu - wiadomo będzie co i gdzie zmienić lub dodać.
